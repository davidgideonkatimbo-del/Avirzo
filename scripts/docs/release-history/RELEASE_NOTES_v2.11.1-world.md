# Avirzo v2.11.1 — Hardened · Feature-capable · World-facing

## Why this release matters
Avirzo is an African heritage cinema studio: oral tradition, documented history, living languages, character continuity, and cinematic export — with costs capped by subscription monthly credits so the platform can sustain itself while creators make work that travels.

## Included since v2.11.0 line
- Regional templates (East, West, Southern, Horn, Nile, classroom)
- First-film path and example gallery
- Community packs + pack import
- Share / watch polish
- Monthly production credits (Free 25 · Creator 300 · Studio 1000)
- Feature-scale sequences: up to 200 scenes / 90 min assembled (Studio)
- Hardening: idempotent grants, generation refunds, 25 automated behavior tests

## Procedure
Web first. Worker optional. Android first-film before next major block. Heritage-first identity unchanged.
