AVIRZO v2.9.3 — GITHUB UPLOAD PACKAGE

IMPORTANT:
This package already has the correct repository directory structure.
Do NOT upload the files from client/src or server/src directly into the GitHub root.

Correct structure:
  client/src/...        -> stays inside client/src
  server/src/...        -> stays inside server/src
  server/package.json   -> stays inside server
  client/package.json   -> stays inside client
  scripts/...            -> stays inside scripts

BEST METHOD:
1. Extract this ZIP on your computer.
2. Open the extracted Avirzo folder.
3. In GitHub, open the Avirzo repository.
4. Use Add file -> Upload files.
5. Drag the CONTENTS of this extracted folder into the upload area while preserving folders.
6. Commit to main.
7. Before deploying Render, confirm the GitHub root shows folders named:
      client
      server
      scripts
   and files such as Dockerfile, package.json, render.yaml, supabase.sql.
8. Open server and confirm it contains:
      package.json
      src
9. Open client and confirm it contains:
      package.json
      src
      vite.config.js
      index.html

DO NOT:
- Upload the ZIP file itself to GitHub.
- Upload client/src files directly to the repository root.
- Upload server/src files directly to the repository root.
- Create an extra Avirzo/Avirzo nested folder.

Render should be deployed only after this structure is confirmed. For the current procedure, deploy the web service first and do not deploy the paid background worker until we explicitly decide to enable it.
