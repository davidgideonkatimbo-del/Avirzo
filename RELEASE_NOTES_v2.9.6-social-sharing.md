# Avirzo v2.9.6 — Social Sharing

- Added mobile-friendly Share video action for completed film exports.
- Uses the Android/iOS system share sheet and shares the MP4 file when the browser supports file sharing.
- Falls back to sharing the export URL or copying the link when file sharing is unavailable.
- Added a clear Download MP4 fallback for Instagram, TikTok, YouTube Shorts, WhatsApp and other platforms that require an uploaded video file.
- Preserved existing export, save, generation and premium studio functionality.
- Social delivery should use 9:16 for vertical short-form platforms; 16:9 remains the cinematic landscape format.
